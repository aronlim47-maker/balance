## Answers, as written

**What was most confusing?**

- T1: "First screen overwhelms with many text and buttons squeezing together that took me some time to digest and understand the situation."
- T2: "Recovery time only show the time planned in today section and there is no sub-section for it to preview in today, hard to identify what type of recovery plan was planned unless the details can be preview in a sub-section under today like how planned task sub-section."
- T3: "the whole ui seems to having lot of text, some element are not intuitive enough (like protected task, idk what the meaning), the sorting in task menu (no indication of it is slidable)"

**Would this help you during exam weeks? Why?**

- T1: "This may help if I have multiple tasks to keep track off but it will be redundant if there's only a little or one to track as I don't need to spend extra time using the app."
- T2: "It would be very helpful for planning up the learn and rest well cycle."
- T3: "Yes, it can help with me know what is due soon and ensure some study time."

**If you could change one thing, what would it be?**

- T1: Different colours for different sections (Today, Availability, Planned tasks); sections closed by default so the first screen is not overwhelming.
- T2: A table view on Today showing the day's plan and schedule with times and durations, with details on scroll or tap.
- T3: Not dark mode by default and follow the system light/dark setting; colours, images and icons; no white flash between pages; a calendar to choose the date on Today; tooltip wording that sounds less AI-written.

## Top problems and what we changed

| # | Problem (who) | What we did |
| --- | --- | --- |
| 1 | Today shows a lot of text and buttons at once; first screen is overwhelming (T1, T3) | Not changed. Today keeps its core sections open so the overload is visible at once; closing them by default and clearer section colours are future work. |
| 2 | Rest time is not visible on Today; a day timetable would help (T2) | Changed: Today now has a Rest time section under Planned tasks showing the day's protected rest with times and total minutes (branch `honor-a11y-evidence`, pending merge). The full day timetable is future work. |
| 3 | Some terms and controls are unclear: "Protected task", the filter row on Quests does not look scrollable; tooltips feel AI-written (T3) | Not changed yet; logged for review. The reported white flash between pages has not been reproduced yet. |
